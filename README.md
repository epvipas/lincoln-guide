# Lincoln Guide

A mobile web app (PWA) for independent Lincoln: places to eat and drink, Steep Hill's shops and galleries, antiques, museums, parks and day trips. Every place has links to Google reviews, TripAdvisor, its own website where it has one, and walking directions in Apple Maps or Google Maps, plus a built-in map.

It's a plain static site with no build step needed to host it. To change the content, edit `build/places.py`, `build/content.html` or `build/info.js`, then run `python3 build/kit/make.py`.
